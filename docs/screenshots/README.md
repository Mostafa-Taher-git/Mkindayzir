## Capture tips

- Use a clean browser profile (dark + light themes).
- Resolution: 1920×1080 or 2560×1440.
- Crop to the app chrome (hide browser tabs/address bar where possible).
- Keep the demo data visible (the seeded OPS project, boards, KB articles, etc.).
- PNG preferred; keep each file under 500 KB.
