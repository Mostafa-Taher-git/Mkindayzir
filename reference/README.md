# Reference Notes

This folder holds short MD references used when building features inspired by or taken from other apps or websites.

## Rules

- Each reference file uses a generic short name (e.g. `reference-app-a.md`, `reference-app-b.md`).
- **Never** include the real name of the source app or website in the file name, in code, in comments, in commit messages, in docs, or anywhere in this project.
- The reference describes only the behavior, layout, flow, or pattern to reproduce — neutrally and generically.
- When the user says "make something like X" or "take from X", create a new MD file in this folder using a generic short name and use it to guide implementation.

## File naming

`reference-<short-name>.md` — short name should be neutral and descriptive of the feature, never the brand.
