# OpenCode task brief — "Authentication required" dialog on http://localhost:5000

## Context (already diagnosed — do NOT re-investigate the server)
The OpsDesk Flask app is NOT the source of the browser's "Authentication required"
(native Basic-Auth) dialog. Evidence already collected on the user's Pop!_OS machine:

- `curl -D - http://localhost:5000/` → `HTTP/1.1 200 OK`, `Server: Werkzeug/3.1.3`,
  **no `WWW-Authenticate` header**.
- `sudo lsof -i :5000` → the ONLY listener is `python` (PID 61441/61444), i.e. the
  OpsDesk `python run.py` process. No ngrok / docker / caddy / nginx / ssh in front.
- No `Basic`/`Authorization`/`WWW-Authenticate` string exists anywhere in the project's
  Python source (`grep -rni basic` across app/*.py is clean except unrelated words).

Conclusion: the server returns 200 with no auth challenge. The native Basic-Auth popup
is therefore coming from the **client/browser side**, not OpsDesk.

## What you must do (investigate + fix on THIS machine)
This is a client-side browser issue. Steps to confirm root cause and resolve:

1. **Read the exact address-bar URL** when the dialog appears. If it is NOT exactly
   `http://localhost:5000/` (e.g. https, a tunnel domain, a different port, or a
   VS Code / Docker forwarded port), that mismatch is the cause — report it.

2. **Incognito test**: open `http://localhost:5000` in a private window.
   - Dialog gone → it is a cached Basic-Auth credential or a browser extension.
   - Dialog still there → the browser is reaching a different endpoint than localhost:5000.

3. **Clear the HTTP auth cache** (if incognito was clean):
   - Chrome: `chrome://net-internals/#auth_cache` → Clear → hard reload `Ctrl+Shift+R`.
   - Also temporarily disable password-manager / SSO / privacy extensions and retry.

4. **Proxy check**: if a proxy (Fiddler/Charles/corporate PAC) is active, set it to
   bypass `localhost`/`127.0.0.1`, or test with the proxy off.

5. **Verify the running server is the OpsDesk one** (sanity):
   `curl -s -D - -o /dev/null http://127.0.0.1:5000/ | head -5`
   Expect `200 OK` and NO `WWW-Authenticate` line.

## Deliverable
Report: (a) the exact URL when the dialog appears, (b) whether incognito showed the
dialog, (c) the fix that resolved it. Do NOT modify any OpsDesk application code
(unless you find, and can prove, that a server-side Basic-Auth middleware exists —
it does not, per the evidence above). If you must change something, it is a
browser/cache/proxy setting, not the Flask app.
