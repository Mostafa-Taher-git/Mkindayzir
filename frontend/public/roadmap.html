Product Roadmap · v1 · 2026

From Local-First to SaaS.

Mkindayzir started as a self-hosted Work OS. V1 takes the next step: a hosted platform on app.mkindayzir.com where teams sign up, log in, and start working — no install, no Docker, no server to manage.

Target

The SaaS Address

When v1 ships, the app lives at app.mkindayzir.com. Users sign up with email or Google, pick a plan, and their workspace is live in seconds.

Phase 1 · MVP Foundation — Multi-Org + Auth + Billing

Multi-Org Workspaces

Organizations, roles (owner/admin/member), recursive workspace copy, org switcher, and the users.onboarded flag that eliminates the infinite onboarding loop.

Backend: organization_service.py, transfer_service.py Frontend: WorkspaceSwitcher, DataPicker, TransitionModal

Clerk Authentication

Sign-in, sign-up, and password-reset driven entirely by Clerk hooks (useSignIn, useSignUp, useAuth). No prebuilt Clerk UI components.

App: humorous-dassie-2146 Static auth pages served by FastAPI on :8000

User Onboarding

Wizard that runs on first visit. Creates the user's initial organization, sets the owner role, and marks onboarded = true.

Model: users.onboarded BOOLEAN Lifespan: migrates from 0 projects heuristic to flag

Team Invitations

Email invite flow: owner/admin sends invitation link, recipient accepts and joins the org with an assigned role. Pending invitations shown in settings.

InvitationService + Invitation model Unique constraint: (org_id, email) to prevent duplicates

SaaS Landing Pages

Marketing pages on app.mkindayzir.com: home, features, roadmap, about. Clear pricing section with Free / Pro / Enterprise tiers. Auth redirects to the console.

Static HTML served by FastAPI on :8000 CTA buttons route to /login and /signup

Stripe Billing

Subscription tiers via Stripe Checkout. Per-seat pricing on Pro and Enterprise. Invoices, receipts, and self-service plan management in user settings.

Stripe webhook for checkout.session.completed Row-level tenant isolation in PostgreSQL
Phase 2 · Growth Post-MVP — Customer Features & Integrations

Customer Portal SPA

Dedicated customer-facing SPA where external users can submit tickets, track status, and chat with the internal team.

Public Knowledge Base

Public help center built from vault notes. Full-text search, feedback voting, and granular publish toggles.

Email-to-Ticket

SendGrid / Mailgun webhooks turn incoming customer emails into auto-assigned support tickets.

SLA Engine

Multi-tier SLA targets with countdowns, warning notifications, and automated escalation to team leads.

Enterprise SSO

SAML 2.0 / OIDC via Clerk: Google Workspace, Microsoft Entra ID, Okta. SCIM user provisioning.

AI Auto-Triage

Private LLM categorizes incoming tickets, estimates priority, and drafts reply suggestions for agent review.

Deployment: Self-Hosted → SaaS

Dimension Self-Hosted (legacy) SaaS (target)
Access Docker install, PostgreSQL config, mkindayzir start Go to app.mkindayzir.com, sign up
Infrastructure Customer-managed server and backups Cloud-deployed, auto-scaling, automated backups
Multi-tenancy One install = one organization Single binary, PostgreSQL row-level tenant isolation
Billing License key or free Stripe: Free / Pro / Enterprise tiers
Updates Manual mkindayzir migrate upgrade Zero-downtime rolling deployments, auto migrations
