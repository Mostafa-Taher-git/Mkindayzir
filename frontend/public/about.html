About

Your operations,
your server.

Mkindayzir is a self-hosted, local-first Work OS built for people who refuse to rent their own data back from someone else's cloud.

"If it leaves your network, it's no longer yours."

Why we built it

Most "work" software is a beautiful cage: smooth interfaces, helpful automations, and a bill that grows with your team. The cost isn't only money — it's custody. Your projects, your knowledge, your decisions, and your customers' data all live on someone else's hardware, behind someone else's terms.

Mkindayzir flips the model. It runs on a machine you control — a laptop, a NAS, a spare server. The interface is the same, but the data never leaves the building unless you explicitly send it.

What we believe

01

Local-first

Your data is stored on your disk, on hardware you control — not rented server time.

02

Yours to leave

No lock-in. Export everything. Move hosts. Shut it down. It's your machine.

03

Quiet by default

No dark patterns, no upsells inside the product. Just the tool.

How it's made

Mkindayzir is a single self-hosted process: a Python FastAPI backend serving both the REST API and the built React/Vite console on one port. Data lives in PostgreSQL 16 — the same engine powers every mode, from a single-user install to a full team. The AI layer is a small companion service that talks to your provider of choice — your API key is encrypted at rest with AES-256-GCM and never logged.

  • FastAPI (Python 3.11+) — async REST API, RBAC, session auth
  • React + Vite console — served by the same process in production
  • SQLAlchemy 2.0 async on PostgreSQL (asyncpg)
  • Ticketing with SLA tracking, Kanban boards, knowledge vault
  • One Docker Compose file for team deployments

Honest roadmap

Email verification codes and an in-app safe updater are designed and scheduled — see the Roadmap page for exactly how updates will protect your data.

Who it's for

Individuals who want a calm, private workspace. Teams who need shared boards and a vault without surrendering data. Companies with compliance needs who must keep operations on-premises. If you value control over convenience, Mkindayzir is built for you.

Start alone. Grow to a team. Expand to the enterprise. Same interface, same data model.
