## Review dimensions
1. **Missing core features / flows**
   - Is there a visible Priority field on tickets, and is it actually stored/enforced?
   - Is there a way to assign a ticket to a specific person? If yes, is the UI discoverable and does the backend enforce it?
   - What is the complete flow for a user to use AI: from adding an API key → choosing a model → invoking AI → seeing output? Is it obvious what the AI can/cannot do?
   - Are there missing CRUD flows, missing filters, missing bulk actions, or dead-end views?

2. **Functional completeness**
   - Ticket lifecycle: create → assign → status changes → resolve → close → reopen. Any missing transitions, missing validations, or inconsistent behavior?
   - Notifications: are they actually delivered/refresh for all relevant events?
   - Reports/SLA/CSAT: are there gaps between what the backend exposes and what the UI consumes?
   - Admin: team/category/user management — are there missing actions or weak validations?
   - Password reset flow: end-to-end usability and security.

3. **AI module completeness**
   - After saving a key + model, does the user know what the AI can do (summarize / suggest reply / suggest priority)?
   - Is the draft-only behavior clearly communicated?
   - What happens when the AI is unavailable, key is wrong, quota exceeded, or model removed? Is the UX graceful?
   - Is there any missing AI capability that would be expected in a help-desk context?

4. **UX/UI gaps**
   - Visual hierarchy, navigation discoverability, role-appropriate nav, empty states, error states, loading states, confirmation flows, undo, breadcrumbs, timestamps, onboarding.
   - Responsive behavior and accessibility issues.
   - Consistency across views.

5. **Security / robustness**
   - Any new auth/RBAC gaps introduced by recent changes?
   - CSRF, session, input validation, error leakage, SQL injection, XSS risks in recent code.
   - Race conditions or weak server-side guards that the frontend doesn’t show.

6. **Data model / migrations**
   - Are there missing columns, indexes, or constraints that would break in daily use?
   - Is the migration path safe for existing SQLite data?
